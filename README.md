# Figure Generation 

## Long-Run Stationarity Stuff

### Eigenstructure of Linear Map on Joint Edge-Label Distribution

`fig/linear_map_eigenvectors.png` generated by `scripts/stationarity-analysis.py` run from `env` in top-level directory. 

To regenerate the figure, run the following command from the top-level directory:

```bash
source env/bin/activate
python -m scripts.stationarity-analysis
```
